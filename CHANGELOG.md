# Changelog

Изменения в проекте Notes_OldReact_Pikabu.

## [1.9.3]
### Изменено
- Заданы фиксированные размеры окон: настройки (380px), список всех заметок (700px).
- Реализовано сохранение активных поисковых запросов и цветовых фильтров при возврате из режима редактирования заметки.

## [1.9.2]
### Добавлено
- В окно «Все заметки» добавлен фильтр по цветам (с возможностью выбора нескольких маркеров).

### Удалено
- Убрана лишняя горизонтальная разделительная линия в окне настроек.

## [1.9.1]
### Добавлено
- Окно «Все заметки» с поиском по нику, алфавитной сортировкой и кнопкой быстрого редактирования заметки.

## [1.9]
### Изменено
- Реализовано динамическое обновление маркеров без перезагрузки страницы (полная перерисовка при сохранении).
- Смещена плавающая кнопка настроек для предотвращения перекрытия элементов сайта.

## [1.8]
### Изменено
- Проведен рефакторинг, код приведен к чистому виду.

## [1.7]
### Изменено
- Изображения реакций переведены в формат Base64.
- Скрипт стал полностью автономным и больше не зависит от внешних серверов или локальных файлов расширения.

## [1.6]
### Добавлено
- Интеграция замены старых реакций (ёлка, череп, голубь) через внедрение внешних CSS-стилей.

## [1.5]
### Добавлено
- Возможность добавлять текстовое описание к каждой прикрепляемой ссылке в заметке.

## [1.4]
### Добавлено
- Палитра расширена до 10 цветов (исключены черный и белый).
- Глобальные описания цветов (тултипы при наведении на маркеры).
- Плавающая кнопка настроек (⚙️) в правом нижнем углу экрана.

## [1.3]
### Добавлено
- Возможность устанавливать до 5 цветных маркеров на одного пользователя.
- Автоматическая миграция базы данных со старого формата (один цвет) на новый (массив цветов).

## [1.2]
### Добавлено
- Прозрачные маркеры (📝) для всех пользователей, чтобы можно было поставить первую заметку без перезагрузки страницы.
- Поддержка отображения маркеров для авторов постов (не только в комментариях).

## [1.1]
### Исправлено
- Ошибки запуска и инициализации скрипта.
- Улучшен механизм вставки маркеров в DOM (использование `.after()` вместо `.insertBefore`).

### Добавлено
- Темная тема оформления для всех модальных окон скрипта.

## [1.0]
### Добавлено
- Базовая версия скрипта.
- Одиночные цветные маркеры для пользователей.
- Текстовые заметки и список ссылок.
- Локальное хранение данных через `GM_setValue`.
