Репа для хранения скриптов для Пикабу. 

Установка скриптов:
1. Отрываем Tampermonkey
2. Выбираем "Создать новый скрипт"
3. В открывшемся окне вставляем текст скрипта
4. Нажимаем "Сохранить"
5. На странице Пикабу выбираем расширение Tampermonkey и включаем скрипт ползунком
6. Обновляем страницу Пикабу.
7. Profit. 


Скрипты:
OldReact_Pikabu - возвращает старые реакции (какашка, петух, клоун)
Notes_OldReact_Pikabu - позволяет делать заметки о пользователях и делать цветную маркировку (несколько цветных маркеров с настройками подписей) З.Ы. Весьма полезно для любителей тэга "политика" (=
